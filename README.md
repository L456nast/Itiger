Грибовед

ИИ-определитель грибов по фотографии



О проекте:

Веб-приложение для определения вида и описания грибов по фото с использованием ИИ.
Цель - снизить риск отравлений при сборе грибов.

Проблема

Ежегодно тысячи людей травятся грибами из-за визуального сходства съедобных и ядовитых видов. Основные причины:

·Сложность отличия съедобных грибов от ядовитых 
·Отсутствие знаний у большинства грибников
·Народные методы проверки не всегда работают
·Нет доступа к эксперту или энциклопедии в лесу
·Бумажные определители сложны для новичков

Статистика: в России ~5000 обращений в год, летальность до 30% при отравлении бледной поганкой.

ЦА:

Новички-грибники 60% 
Семьи с детьми 15% 
Туристы 12% 
Люди на пенсии 8% 
Профессионалы 5% 

Основные боли: страх ошибки, нет обратной связи в лесу, долгое ожидание ответа от экспертов.


Решение

Приложение определяет гриб по фото и выдаёт:

· Название 
· Съедобен / ядовит 
· Рекомендацию по употреблению
· Признаки для проверки
· Предупреждение для ядовитых грибов

Дополнительный функционал: каталог 150+ видов, избранное, история определений, статистика.



MVP

Что реализовано:

· Бэкенд 
· База 150 видов грибов
· Загрузка фото )
· Определение с точностью 90%
· Каталог с фильтрацией и поиском
· Избранное и история
